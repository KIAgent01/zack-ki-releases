# Zack KI

**Ask. Get the answer. Keep working.**

Zack KI puts AI where you are already working. Select text or files in a Windows app, press **Alt+1**, and ask your question. The answer can go back into the place you marked.

## AI without leaving your work

A simple question should not require copying context into a browser, switching windows, and pasting the answer back. Zack KI keeps the workflow in the app you are already using:

**Select → press Alt+1 → ask → continue working.**

## Bring context, not copy-paste

Whatever helps answer the question can come along with it.

| | |
|---|---|
| ⌨️ **Selected text** | Select a paragraph in Word, Outlook, a browser or another Windows app. The selection is attached to your question. |
| 📎 **Files from Explorer** | Select PDF, Word or Excel files in File Explorer and ask about them without opening them first. |
| 🖼️ **A region of your screen** | Nothing selected? Drag a box around an error message, chart or form and ask about it. |
| ↩️ **Answer in place** | When useful, the answer can be inserted back where your selection was. |

## What Zack KI can help with

- Improve or rewrite selected text.
- Explain what a document, file or screen region shows.
- Compare information across selected files, such as a quote and a price list.
- Summarize, translate or answer questions about the context you selected.
- Choose **Quick** for an immediate answer or **Deep** when a harder question deserves more time.

## Why Zack KI feels faster

Without Zack KI, a quick question often means:

1. Select text
2. Copy it
3. Open an AI tool
4. Paste the context
5. Ask
6. Copy the answer
7. Switch back
8. Find the right place
9. Paste it

With Zack KI, the context is already attached and the answer can return to the marked spot.

## Privacy

- Chats are stored **locally on your PC**.
- Zack KI's servers run **in Germany** and **do not keep your requests**.

Read the full privacy information on the [Zack KI website](https://zack-ki.com/en).

## Installation

1. Download [Zack-KI.exe](https://zack-ki.com/downloads/Zack-KI.exe).
2. Run the installer.
3. Select text or files in Windows.
4. Press **Alt+1** and ask.

## Requirements

- Windows 10 or Windows 11.
- There is currently no macOS or Linux version.
