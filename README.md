**An AI behind a keyboard shortcut, not behind a browser tab.**

Select text or files in any Windows app, press **Alt+1**, ask. Whatever you selected is already attached to the question, and the answer can go back into the spot you marked.

## What it does

| | |
|---|---|
| ⌨️ **Works everywhere** | Alt+1 in any application, no window to switch to. |
| 📎 **Files come along** | Select PDF, Word or Excel in the Explorer and ask about them without opening them. |
| 🖼️ **Ask about a region** | Drag a box on screen and ask what's in it. |
| ↩️ **Answer in place** | The reply lands back at your selection instead of in a chat log. |
| ⚡ **Quick and Deep** | Quick answers immediately, Deep takes its time on the harder questions. |

## Why

Checking a quote against a price list used to mean two open PDFs, a browser tab, and copying numbers by hand. Now it's: select both files, Alt+1, ask what doesn't match.

## Privacy

- Chats are stored **locally on your PC**, not with us.
- The servers run **in Germany** and **don't keep your requests**.

## Install

1. Download [Zack-KI.exe](https://zack-ki.com/downloads/Zack-KI.exe) and run it.
2. Select some text and press **Alt+1**.

Requires **Windows 10 or 11**. There is no macOS or Linux version.
